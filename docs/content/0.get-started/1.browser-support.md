## Overview

The `@webext-core` packages will work on:

| Browser               | Supported Versions |
| --------------------- | ------------------ |
| Chrome                | >= 87              |
| Firefox               | >= 78              |
| Safari <sup>_1_</sup> | >= 14              |
| Edge                  | >= 88              |
